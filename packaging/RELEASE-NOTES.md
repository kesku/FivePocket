# FivePocket Duo {version}

FivePocket Duo runs a locally rebuilt copy of your own game on iPhone Duo.
The Mac builder uses your two Xbox 360 disc images to make an unsigned app;
sign it with your Apple identity and import the game files on the device.

Portrait split places the game above the map, wheels and phone. Landscape
uses the full display. Gamepad and touch controls are supported.

The download contains the Mac Duo builder and its source. No game files,
generated game code or ready-made IPA are distributed. Keep the builder's
bundle identifier when signing updates so the app retains its data and saves.

Source: `FivePocket-{version}-source.tar.xz` (GPL-3.0-or-later).
Verify downloads against `SHA256SUMS` and the table below.
